## 📌 Executive Summary

Modern generative artificial intelligence has fundamentally altered the digital disinformation landscape. High-fidelity latent diffusion engines (**Midjourney v5/v6**, **DALL-E 3**, **Stable Diffusion XL**) synthesize photojournalism featuring natural lighting, correct geometric perspectives, and realistic skin textures, while frontier Large Language Models (**GPT-4**) craft persuasive, context-aware news captions. Human evaluators—including graduate computer science researchers—achieve only an $\text{F1-Score} \approx 60.2\%$ when attempting to discern authentic news from synthetic pairs.

**VeritasNet** is an end-to-end multimodal deep learning system designed to detect contextual inconsistencies between news photojournalism and accompanying headlines. Rather than performing open-web fact-checking, VeritasNet assesses **closed-world cross-modal alignment**: verifying whether the visual evidence in the photograph corroborates the semantic propositions of the text.

Built on the **MiRAGeNews** benchmark (*Findings of EMNLP 2024*), VeritasNet demonstrates that an engineered, lightweight architecture—combining a pretrained **ResNet-18 CNN**, a sparse **TF-IDF bigram extractor**, and a custom **PyTorch Multi-Layer Perceptron (MLP)** with targeted differential fine-tuning—achieves **91.20% Test Accuracy** ($0.9118$ **Macro-F1**) on unseen data, outperforming unimodal text baselines by $+15.67\%$ and zero-shot multimodal foundation models by over $+65\%$ **F1**.

## 🔬 Core Research Hypotheses

* **Hypothesis 1 (Cross-Modal Synergistic Lift):** Unimodal text classifiers overfit to headline lexical frequencies and publisher stylistic quirks. Integrating spatial visual representations extracted by a deep convolutional network provides complementary inductive bias, breaking unimodal memorization and yielding a statistically significant performance gain ($> 10\%$) on identical evaluation splits.

* **Hypothesis 2 (Targeted Transfer Learning via Layer-Specific Fine-Tuning):** In compute-constrained environments, freezing early general-purpose visual layers ($\text{conv1}$ through $\text{layer3}$) while unfreezing only the high-level semantic block ($\text{layer4}$) with differential learning rates ($\eta_{\text{backbone}} \ll \eta_{\text{head}}$) allows the model to adapt to journalistic image distributions without catastrophic forgetting of foundational ImageNet visual priors.

* **Hypothesis 3 (Figurative Language Attenuation):** Journalistic headlines frequently deploy non-literal figures of speech (e.g., *"Senator under fire"*). While single-word lexical models trigger false mismatches against standard press photos, bigram lexical modeling ($n$-gram range $1$ to $2$) provides localized multi-word grouping that helps bridge the gap between figurative language and literal visual evidence.

## 🧹 Data Engineering & Zero-Leakage Pipeline

To ensure empirical validity, all preprocessing and partitioning follow strict data leakage safeguards.

Raw Parquet (10,000 Rows)
       │
       ▼
[Row-Level Cleaning & Image MD5 Hashing] ──► Dropped 3 Corrupt/Duplicate Rows (9,997 Left)
       │
       ▼
[Stratified Random Splitting (Seed=42)]
       ├── Train Split (70%): 6,997 Samples (3,497 Class 0 / 3,500 Class 1)
       ├── Val Split   (15%): 1,500 Samples (  750 Class 0 /   750 Class 1)
       └── Test Split  (15%): 1,500 Samples (  750 Class 0 /   750 Class 1)
       │
       ▼
[Zero-Leakage Feature Extraction]
       ├── TF-IDF Vocabulary (5,000-D): Fitted EXCLUSIVELY on Train Headlines
       └── ResNet-18 (512-D): Precomputed under torch.no_grad() & Cached to Drive


1. **Row-Level Sanitization:** Stripped HTTP/HTTPS URLs, eliminated HTML markup, purged non-alphanumeric punctuation, normalized whitespace sequences, and cast all strings to lowercase.
2. **Cryptographic Image Deduplication:** Computed MD5 hashes on raw image byte payloads:
   $$\text{Hash}_{\text{MD5}} = \text{MD5}(\text{image}[\text{'bytes'}])$$
   Identified and removed cross-row visual duplicates, leaving **9,997 clean records** ($5,000\text{ Class 1} \,/\, 4,997\text{ Class 0}$).
3. **Stratified Partitioning ($70/15/15$):** Enforced balanced class distributions across all cohorts using `random_state=42`.
4. **Fit-on-Train Protocol:** Scikit-Learn's `TfidfVectorizer` was fitted **strictly on the 6,997 training headlines**. Validation and test headlines were transformed using the frozen training vocabulary, eliminating vocabulary leakage.
5. **Set Disjointness Verification:** Automated assertions confirmed $0$ intersecting headlines across splits:
   $$\text{Set}(\text{Text}_{\text{train}}) \cap \text{Set}(\text{Text}_{\text{val}}) = \emptyset, \quad \text{Set}(\text{Text}_{\text{train}}) \cap \text{Set}(\text{Text}_{\text{test}}) = \emptyset$$

## 🏗️ VeritasNet Architecture Specifications

VeritasNet utilizes an early-fusion deep neural network (`VeritasNetFusion`) implemented in PyTorch.


   [ Headline Text ]                              [ News Image ]
          │                                              │
   TF-IDF Vectorizer                              ResNet-18 Backbone
(Unigrams + Bigrams)                          (Pretrained ImageNet Weights)
          │                                              │
  Vector: [Batch, 5000]                          Vector: [Batch, 512]
          │                                              │
 Linear Layer (5000 -> 256)                     Linear Layer (512 -> 256)
 LayerNorm + ReLU + Dropout                     LayerNorm + ReLU + Dropout
          │                                              │
 Embedding: [Batch, 256]                        Embedding: [Batch, 256]
          └──────────────────────┬───────────────────────┘
                                 │
                         Early Concatenation
                        Vector: [Batch, 512]
                                 │
                         Linear (512 -> 64)
                            ReLU + Dropout
                                 │
                         Linear (64 -> 1)
                                 │
                        Output: [Batch, 1]
                   (Unscaled Scalar Logit z)


### Layer-by-Layer Dimension & Parameter Audit

| Component | Sub-Layer | Input Dim | Output Dim | Activation / Regularization | Parameter Count |
| :--- | :--- | :---: | :---: | :--- | :---: |
| **Text Branch** | `Linear` | 5,000 | 256 | $\text{ReLU}(), \text{Dropout}(p=0.3)$ | 1,280,256 |
| **Image Branch** | `Linear` | 512 | 256 | $\text{ReLU}(), \text{Dropout}(p=0.3)$ | 131,328 |
| **Fusion Layer** | `torch.cat` | $256 + 256$ | 512 | Identity pass-through | 0 |
| **Classifier Head** | `Linear` | 512 | 64 | $\text{ReLU}(), \text{Dropout}(p=0.2)$ | 32,832 |
| **Output Layer** | `Linear` | 64 | 1 | Raw Logit ($z \in \mathbb{R}$) | 65 |
| **Total Head** | *All Trainable* | — | — | **BCEWithLogitsLoss** | **1,444,481** |

* **Numerical Stability:** The model emits unscaled logits evaluated via `nn.BCEWithLogitsLoss`, leveraging the log-sum-exp trick to prevent vanishing/exploding gradients:
  $$\mathcal{L}_{\text{BCE}}(z, y) = \max(z, 0) - z \cdot y + \log\left(1 + e^{-|z|}\right)$$

## ⚡ Two-Stage Training & Optimization Strategy

To prevent Google Colab Out-Of-Memory (OOM) crashes and achieve fast convergence, training was structured into two targeted stages:

### Stage 1: Transfer Learning via Frozen Feature Caching

* **Backbone:** Torchvision pretrained ResNet-18 ($\text{fc} = \text{Identity}$).
* **Mechanism:** ResNet-18 was frozen (`requires_grad = False`). Spatial feature vectors ($512\text{-D}$) were precomputed under `torch.no_grad()` and cached directly to Google Drive as `.npy` arrays.
* **Optimization:** The fusion head was trained on cached vectors for 10 epochs using $\text{Adam}(\eta = 10^{-3}, \text{weight\_decay} = 10^{-4})$ with batch size 32.
* **Runtime:** $\sim 1.8$ seconds per epoch ($\sim 20$ seconds total). Peak validation accuracy ($85.87\%$) was achieved at Epoch 2. Checkpoint selection at this peak prevented empirical text overfitting.

### Stage 2: Targeted Backbone Fine-Tuning

* **Mechanism:** The top convolutional block of ResNet-18 ($\text{layer4}$, containing $8.4\text{M}$ parameters) was unfrozen, while lower layers ($\text{conv1}$ through $\text{layer3}$) remained locked.
* **Differential Learning Rates:**
  $$\eta_{\text{backbone}} = 1 \times 10^{-5} \quad \ll \quad \eta_{\text{head}} = 1 \times 10^{-4}$$
* **Catastrophic Forgetting Safeguard:** Training was restricted to 3 epochs using a batch size of 16. This allowed the convolutional filters to adapt to photojournalistic features without overwriting ImageNet representations. Validation accuracy climbed from $88.87\% \to 91.27\%$.

## 🧩 Figurative Language Analysis & Future Roadmap

### The Idiomatic Mismatch Error Mechanism

Qualitative error analysis revealed that remaining false-positive misclassifications cluster around headlines using metaphoric idioms:

* *"Wall Street in the red"* $\implies$ Photo shows a standard trading floor (no red tint).
* *"Senator under fire during briefing"* $\implies$ Photo shows a standard press podium (no literal flames).
* *Cause:* ResNet-18 detects literal physical objects (podiums, trading floors), penalizing authentic news when figurative expressions do not appear in the image.

### Proposed 4-Class Semantic Taxonomy & Idiom Gate

To resolve this limitation, VeritasNet formulates a **4-class semantic taxonomy** driven by an `idiom_flag` ($s_{\text{idiom}} \in \{0.0, 1.0\}$) scanning for financial, crisis, and conflict metaphors:

| Raw Label | Idiom Flag | Target Custom Class | Semantic Description |
| :---: | :---: | :--- | :--- |
| **Matching (0)** | 1.0 | `metaphorical_match` | Image matches figurative headline meaning without literal depiction. |
| **Matching (0)** | 0.0 | `literal_match` | Headline is literal and directly depicted in the image. |
| **Mismatch (1)** | 1.0 | `topical_only` | Image and text share an overarching theme but contradict specific claims. |
| **Mismatch (1)** | 0.0 | `unrelated` | Complete visual and semantic divergence with zero contextual overlap. |


                   [ Input Headline ]
                           │
                  Rule-Based Lexicon
                           │
             ┌─────────────┴─────────────┐
             ▼                           ▼
      s_idiom = 0.0               s_idiom = 1.0
      (Literal Text)            (Figurative Text)
             │                           │
             ▼                           ▼
    Require Strict Object      Attenuate Visual Penalty
     Visual Verification        via Learned Gating Weight


### Phased Engineering Roadmap

* **Phase 1 (Idiom Gating):** Inject the scalar score $s_{\text{idiom}}$ into the fusion layer ($512\text{-D} \to 513\text{-D}$), training the MLP to dynamically attenuate visual penalties when figurative text is present.
* **Phase 2 (Dense Semantic Encoders):** Replace TF-IDF with a compact Sentence-Transformer (`all-MiniLM-L6-v2`, $384\text{-D}$) to capture sentence-level semantics within Colab RAM constraints.
* **Phase 3 (Cross-Attention Fusion):** Replace vector concatenation with bidirectional cross-attention layers, mapping localized visual bounding regions directly to corresponding headline tokens.

## 🚀 Reproduction & Execution Guide

### Prerequisites

* Google Account with Google Drive access.
* Google Colab session with GPU acceleration enabled (**Runtime > Change runtime type > T4 GPU**).

### Execution Sequence

#### 1. Environment Diagnostics
Open and execute `notebooks/Environment_Setup.ipynb`:
* Mounts Google Drive at `/content/drive/MyDrive/VeritasNet`.
* Verifies Python 3.10+, PyTorch 2.0+, and NVIDIA Tesla T4 GPU allocation.
* Generates directory structure.

#### 2. Data Preparation & Preprocessing
Open and execute `notebooks/DataPreperations.ipynb`:
* Loads `data/raw/mirage_news_raw.parquet` ($10,000$ instances).
* Performs MD5 image hashing and text sanitization ($9,997$ records retained).
* Executes stratified $70/15/15$ splitting with `random_state=42`.
* Fits `TfidfVectorizer(max_features=5000, ngram_range=(1,2))` on training headlines only.
* Serializes processed splits and vectorizer artifacts.

#### 3. Training, Evaluation & Benchmarking
Open and execute `notebooks/training_Evaluation.ipynb`:
* **Cell 2:** Trains and evaluates the text-only Logistic Regression baseline ($75.53\%$ test accuracy).
* **Cell 3:** Precomputes 512-D visual feature vectors using pretrained ResNet-18 under `torch.no_grad()`.
* **Cell 4:** Initializes PyTorch multimodal DataLoaders.
* **Cell 5:** Instantiates the `VeritasNetFusion` network architecture.
* **Cell 6:** Executes Stage 1 training (10 epochs); saves best checkpoint at Epoch 2 ($85.87\%$ val accuracy).
* **Cell 7:** Evaluates Stage 1 model on the test set ($86.27\%$ test accuracy).
* **Cell 8:** Executes Stage 2 targeted fine-tuning on ResNet-18 `layer4` (3 epochs, differential learning rates).
* **Cell 9:** Evaluates champion model on unseen test set ($91.20\%$ test accuracy, $0.9118$ Macro-F1).
